# 奥田制作所 技術ノート

## 概要

このリポジトリは、私（奥田 智紘）が学習してきた知識を公開するものです。

Java や Kotlin を含む Android アプリ開発に関する技術的な知識を中心とした内容となっておりますが、マテリアルデザインや Figma の使い方から、プログラミングのデザインパターンなど、アプリ開発に必要な様々な知識を公開しております。

採用担当の方には、私の技術力や経験を把握する指標としてご覧いただければ幸いです。

エンジニアの方には、私の技術や経験をご自身の開発に活かしていただければ幸いです。


## リポジトリの公開

このノートは、 2017 年頃から自分用のメモやノウハウ集として書き始めました。

しばらくの間は非公開としてきましたが、 2025 年現在、公開することにしました。

公開するに至った主な理由は、自分の実績を対外的にアピールし、信頼を得るためです。これにより、皆様からより安心してお仕事をご依頼いただけるようにしたいと考えております。

もともとは自分用のメモとしていたこともあり、対外向けの資料になっていない部分も多いですが、少しずつ整備していく予定です。

以前は、リポジトリ内に機密情報も含まれていたため、公開するためには、履歴を削除する必要がありました。そのため、リポジトリを一度削除してから作り直しています。よって、最近作られたリポジトリに見えますが、実際には 2017 年頃から書き始めた内容になります。


## 参考文献

この技術ノウハウは、主に以下の方法で調査した内容に対して、不足している情報などを追加調査したり検証して、ブラッシュアップしたものになります。

- Android や Kotlin をはじめとした各種公式ドキュメント
- 他のエンジニアさんがインターネット上で公開されている情報
- 書籍


## 公式ドキュメントを翻訳する作業について

公式ドキュメントを翻訳する作業は、「ツールを通せばすぐにできる作業で、あまり価値のない作業」だと思われる方も多いかもしれません。しかし、私は、公式ドキュメントを翻訳する作業が、非常に価値のある作業であると考えています。

特に、 Android アプリ開発の公式サイト（Android Developers）の日本語訳ページは、機械的に翻訳されており、ベテランエンジニアが読んでも理解できないことが多々あります。

私は、そのようなドキュメントを原文（英語）から翻訳して、「意味が通る文章になって、内容が理解できるか？」を確認しながら、このリポジトリに記録しています。もちろん、ツールを通して翻訳した内容をコピペで記録するだけでは、ほとんど意味がないと考えています。しかし、このリポジトリに記録している内容は、翻訳後に私が理解した内容がほとんどです。

中には、どれだけ一生懸命にドキュメントを読んでも理解できない場合もあります。そのような場合は、公式ドキュメントの下部に配置された「評価ボタン」で低評価を押すと、「なぜ低評価なのか」を選択するダイアログが表示されるため、そこで、「情報が不足しているため」などの原因を選択して、 Google に意思表示するようにしています。

## 活用方法

エンジニアの方向けに、このリポジトリを十分に活用する方法をご説明します。

### 公式ドキュメントの補助資料

このリポジトリでは、 Android や Kotlin の公式ドキュメントを読んでも理解できなかった場合に、補助資料として使用することができます。

各種公式ドキュメントに対して、十分な補足やより丁寧な解説を加えて、このノートを作成しています。

また、公式ドキュメントは、機械翻訳されているために、日本語として意味が通らないことが多々あります。このリポジトリでは、英文を自分で読んで翻訳したり、より精度の高い翻訳ツールを使って翻訳することで、精度の高い日本語訳になっています。


### 知りたいことを検索

リポジトリ内で知りたい内容のキーワード検索をすることで、知りたい内容がピンポイントで出てくる可能性があります。
