# 概要

- 標準と連結の 2 種類のボタングループ
- 押下時、および、選択時に形状の変形を適用
- 連結ボタングループは、 [分割ボタン ( Segmented button )](https://m3.material.io/m3/pages/segmented-buttons/overview) に代わるものです。
- すべてのボタンサイズ（XS、S、M、L、XL）に対応
- 単一選択、複数選択、選択必須に対応

## 標準ボタングループと連結ボタングループの違い

|                                    | 標準ボタングループ | 連結ボタングループ |
| ---------------------------------- | ------------------ | ------------------ |
| 同じグループ内のボタン同士の関連性 | 低い               | 高い               |
| 非選択時の形状                     | 楕円               | 四角形             |
| 選択時の形状                       | 四角形             | 楕円               |
| Segmented button の代替            | 不可               | 可                 |

重要なポイントは、標準ボタングループは、グループ内のボタン同士の関連性が低く、連結ボタングループは関連性が高いという点です。

そのため、標準ボタングループでは、ボタン同士が少し離れて見えるように、非選択時のボタンの形状が楕円になっています。連結ボタングループは、その逆で、ボタンの形状が四角になっています。
