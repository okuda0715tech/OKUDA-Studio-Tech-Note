# ヒープ・スタック・メソッド領域の違い

## スタック（Thread Stack）

- 各スレッドごとに存在
- 関数呼び出しの一時領域
- ローカル変数、引数、呼び出し情報（フレーム）が載る
- 関数を呼び終わったら一気に解放される
  - **一番よく変化する領域**


## ヒープ（Heap）

- new で作られたインスタンス（オブジェクト）が置かれる
- GC（Garbage Collector）が回収する
  - **動的に増減する領域**


## メソッド領域（Method Area / Class Space）

- ロードされたクラス情報を保持
- 関数（メソッド）のバイトコード
- 定数（Constant Pool）
- static フィールド（プロパティ）の値
- メソッドテーブル
  - **クラスごとに固定で、基本的にプロセス終了まで残る**
