# RPC

## 概要

RPC ( Remote Procedure Call ) とは、直訳すると 「遠隔手続き呼び出し」 となります。手続きは関数のことを意味します。つまり、 「呼び出し元と呼び出し先が物理的に離れていても、関数呼び出しの形で処理できる仕組み」 のことを RPC と呼びます。


## 例

例えば、 Android では、プロセス間通信として AIDL (Android Interface Definition Language) が使われたり、クライアントサーバー間通信として、 gRPC が使われることがあります。

gRPC では、 .proto ファイルに関数のインターフェース的な定義を記述し、 gRPC 用の Gradle プラグインを追加してビルドすることでそれらの関数が実際に生成され、 Android アプリからそれらの関数を呼び出すことが可能になります。

AIDL は、 gRPC における .proto ファイル的な役割を果たします。
